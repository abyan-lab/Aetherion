## 🌟 About The Project
**Aetherion** is an immersive, interactive 3D browser world built around a scroll-driven camera flythrough. As users scroll, the camera glides past a crystal citadel, crosses glowing energy bridges, and arrives at a living, draggable core (The Heartstone) powered by custom GLSL shaders.

---

## 🛠️ Tech Stack & Features
- **Core & Rendering:** React, Vite, React Three Fiber (Three.js 3D scene engine).
- **Custom Shaders:** Hand-written GLSL plasma materials utilizing simplex-noise displacement for the Heartstone core and an energy-field shell.
- **Environment & Effects:** `@react-three/drei` (Float, Sparkles, Stars, Environment, 3D-anchored HTML UI hotspots) and `@react-three/postprocessing` (Bloom, God Rays, Chromatic Aberration, Vignette).
- **Styling & Typography:** Plain CSS with custom variables, featuring *Cinzel* and *Space Grotesk* from Google Fonts.
